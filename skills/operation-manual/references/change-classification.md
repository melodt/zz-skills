# 变更分类

## 进入用户手册

- 新增或修改前端路由、菜单、页面字段、按钮、表单校验或页面状态。
- 修改权限、角色、可见性、审批或状态流转。
- 修改 API 请求或响应字段、错误码、成功结果，且会改变用户操作或页面行为。
- 修改默认值、限制、超时、批量规则或其他用户可感知约束。

## 通常不进入用户手册

- 内部重构、性能优化、日志、监控、存储迁移或测试重排，且页面和用户行为不变。
- 只有内部调用方使用、没有用户入口的后端接口。

## 待人工确认

- 代码变更与现有页面说明矛盾。
- 无法判断后端契约是否被前端或外部用户使用。
- 只有生产环境可验证，或缺少安全的测试数据、账号和权限。
