# 项目级测试用例规则模板

将以下内容合并到需要此工作流的目标项目的 `AGENTS.md`；先安装 `test-case-workflow`，并保留现有项目规则。此规则只对采纳它的项目及其适用范围生效，是 Agent 指令，不是技术强制门禁。

```markdown
## 测试用例与完成条件

基于 spec、ticket 或详细设计进行实现或验收时，先读取并应用已安装的 `test-case-workflow` skill，维护按功能组织、可追溯来源和 ticket 的测试用例及执行证据。直接调用第三方 `implement` 或 `implement-spec` 时也适用。

实现前准备用例；在声明当前范围验证完成及执行受影响的提交、关闭 ticket、将 PR 标为待评审等完成动作前，逐条验证该范围的适用用例，且全部有有效通过证据。完整 spec 还须验证集成后的跨 ticket 和受影响场景。失败、阻塞、待确认、未执行和需复验都不是通过；报告结果并暂停受影响完成动作。用户明确批准缩小范围时，记录并报告排除项，不声称原范围通过。

如该 skill 不可用，或第三方流程无法在完成动作前执行验证，报告原因并暂停受影响完成动作；不要修改第三方 skill 绕过门槛。提交、外部发布和工单操作仍须遵循用户授权及其他适用规则。
```
